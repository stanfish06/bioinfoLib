# bioinfoLib Examples

This directory contains Jupyter notebooks demonstrating the usage of bioinfoLib.

## Notebooks

1. `scRNAseq_analysis.ipynb` - Basic single-cell RNA sequencing analysis workflow
2. `image_processing.ipynb` - Image analysis and processing examples
3. `gaussian_process.ipynb` - Gaussian Process modeling examples

## Running the Examples

1. Make sure you have Jupyter installed:
```bash
pip install jupyter
```

2. Install the bioinfoLib kernel:
```bash
python -m ipykernel install --name='bioinfoLib' --user
```

3. Launch Jupyter:
```bash
jupyter notebook
```

4. Navigate to the examples directory and open any notebook.
